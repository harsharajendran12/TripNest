# TripNest Architecture

React/Vite -> REST API -> Spring Boot -> JPA/Hibernate -> MySQL

Core database modules:
- Users/authentication
- Trips
- Destinations
- Trip members/groups
- Itineraries
- Budgets and expenses
- Documents
- Notifications
- Refresh tokens
